# Hospital Patient Appointment Management Website

A refactored, semantic and accessible hospital website for viewing services, doctor information and booking patient appointments.

## Technologies
- HTML5
- CSS3
- Git
- GitHub

## Features
- Semantic HTML structure
- Accessible patient appointment form
- Keyboard-friendly navigation
- Before-and-after accessibility audit
- Git feature branch and GitHub Pull Request

## How to run
Open `labexpt2.html` in a web browser.

## Accessibility testing
Run Lighthouse from Chrome Developer Tools or use the WAVE extension.
